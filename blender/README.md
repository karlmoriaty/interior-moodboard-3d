# Blender 场景管线

## cafe-scene.py

林间咖啡馆的 Blender 仿真场景，Cycles 渲染。

坐标约定（全程一致）：

- X 向右，Y 向房间深处（Y=0 是窗墙，Y 越大越靠近相机），Z 向上
- 所有建体函数参数顺序统一为 (宽, 深, 高, x, y, z)
- 房间 6.8 × 5.6 × 3.0 米

包含：三扇半圆拱窗（曲线做的真拱）、木梁、整面书架（五层塞满书）、
吧台（柜体/台面/咖啡机/玻璃展示柜/菜单黑板）、藤编椅、圆桌、矮茶几、
蜡烛群、环形吊灯（垂挂绿植）、壁炉柴火、窗外花园背景、体积雾。

运行方式：

    blender --background --factory-startup --python blender/cafe-scene.py

## night-scene.py

夜景公寓的 Blender 仿真场景，Cycles 渲染。

关键做法（踩了三轮才定下来）：

- **城市用真实照片，不用程序化楼群**。程序化楼群试过三轮：
  楼放近（9–26 米）被拉伸成白竖条，放远（60–400 米）又被体积雾糊平，
  贴图在每栋楼只映射一次，怎么调都不像真实城市。
  最后改用参考图裁出的窗外区域（crop-city.py 生成 city-crop.jpg），
  贴在窗外 16 米处。真实度直接等于参考图。
- **不建玻璃**。Cycles 里 transmission 玻璃会把窗外折射糊成一片蓝灰，
  而参考图的玻璃几乎不可见。只留窗框，视线直接穿过去。
- **室内压到接近全黑**。灯带面光 20–34 W、蓝 LED 自发光 5.5、
  城市冷光 90 W。参考图是「暗部真黑、只有光源附近亮」，
  灯带功率按 320/200 试过，天花板直接变浅灰，完全不对。

## 已知天花板

当前是「风格化 3D 渲染」，不是照片级写实。差距在两处：

1. 模型精度：书架是盒子、书是方块。参考图里每本书都是独立模型。
2. 材质贴图：程序化 PBR（木纹用 wave 节点、织物用 noise）只能做到
   有点像，真写实需要扫描贴图（albedo / normal / roughness 各一张）。

这两项都要外部资产库，本机无网络、无素材库的情况下做不到。
