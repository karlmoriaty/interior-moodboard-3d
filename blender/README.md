# Blender 场景管线

## cafe-scene.py

林间咖啡馆的 Blender 仿真场景，Cycles 渲染。

坐标约定（全程一致）：

- X 向右，Y 向房间深处（Y=0 是窗墙，Y 越大越靠近相机），Z 向上
- 所有建体函数参数顺序统一为 (宽, 深, 高, x, y, z)
- 房间 6.8 × 5.6 × 3.0 米

包含：三扇半圆拱窗（曲线做的真拱）、木梁、整面书架（五层塞满书）、
吧台（柜体/台面/咖啡机/玻璃展示柜/菜单黑板）、藤编椅、圆桌、矮茶几、
蜡烛群、环形吊灯（垂挂绿植）、壁炉柴火、窗外花园背景、体积雾。

运行方式：

    blender --background --factory-startup --python blender/cafe-scene.py

## 已知天花板

当前是「风格化 3D 渲染」，不是照片级写实。差距在两处：

1. 模型精度：书架是盒子、书是方块。参考图里每本书都是独立模型。
2. 材质贴图：程序化 PBR（木纹用 wave 节点、织物用 noise）只能做到
   有点像，真写实需要扫描贴图（albedo / normal / roughness 各一张）。

这两项都要外部资产库，本机无网络、无素材库的情况下做不到。
